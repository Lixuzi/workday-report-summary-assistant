# 平台说明

核实日期：2026-09-10

- 目标人群固定为 ChatGPT Pro 用户；完整流程依赖 macOS 桌面端 Computer History 和 Memories，需使用者启用
- Computer History 的已获准应用/网站活动可以供 ChatGPT 与 Codex 使用，不能据此推断普通网页聊天或任意环境都能读取本机历史
- 原始事件有保留期限，长期总结主要依靠现有摘要与用户工作归档；记录暂停或缺口不能推断为没有工作
- Skill 包不会开通套餐、启用记录、安装 Computer History 或创建定时任务。先检查当前实际能力，有缺项说明具体原因
- 发布与安装界面可能变化。此包为标准 Skill 源文件，未上架公共插件目录；需要插件方式分发时按官方文档封装，不能声称本包已经发布
