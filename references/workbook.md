# Excel 与生成脚本

默认模板为 `assets/report-template.xlsx`，不含真实项目、历史数据、宏、外链或个人元数据。版式继承已确认日报；日期颜色以该用户第一次有效日报日期为蓝色起点，按自然日交替，跳过无工作日不改变奇偶顺序

## 版式约定

| 内容 | 默认格式 |
|---|---|
| 工作表 | 单表“工作日报” |
| 列 | A 分类 / B 项目 / C 今日进展 / D 待跟进 |
| 列宽 | 110 / 205 / 440 / 290 像素 |
| 标题 | A1:D1 合并，Helvetica Neue 22 号、深蓝、粗体 |
| 表头 | 第 3 行，浅蓝灰 #E8EEF4，12 号粗体，27 磅行高 |
| 日期 | A:D 合并，真实日期值，yyyy-mm-dd，16 号，27 磅行高 |
| 日期颜色 | 淡蓝 #BFE5F2 / 淡红 #FCE4E4，按自然日交替 |
| 正文 | 12 号，项目粗体，白色/浅灰 #F6F8FA 交替，细底边框，自动换行 |
| 分类 | 同一天相同分类相邻、A 列纵向合并，11 号灰蓝色 |
| 对齐与冻结 | 全部水平和垂直居中；冻结 A4 |

Helvetica Neue 是原模板字体；未安装时使用可用等效字体并检查渲染，不要求使用者安装特定字体。长文本可增加行高，不能通过缩小正文到不可读来强行塞入

## 可复用生成器

`scripts/render_report.mjs` 使用当前环境提供的 `@oai/artifact-tool` 生成同版式工作簿，另存输入证据 ledger，支持 `--previous` 合并上次 ledger。`scripts/report_data.mjs` 只负责日期、稳定 id 和历史合并，不判断业务事实

遵循当前可用的表格 Skill 和运行时依赖说明。复制 scripts 到本任务工作目录，使用工具实际返回的 Node 与依赖路径；不要复制作者电脑的绝对路径，不修改运行时目录，不默认从网络安装包。若当前环境没有这个库，使用可用表格工具在模板副本上完成同样流程，并执行下列检查

命令示例中的文件路径由当前任务实际位置替换：

```sh
node render_report.mjs --input today.json --previous ledger-before.json --xlsx 工作日报-YYYYMMDD.xlsx --ledger ledger-after.json --preview preview
```

首次生成省略 `--previous`。输入示例见 [虚构数据](example-report.json)；示例只用于理解和测试，不能作为使用者的工作证据

输入包含 `schema_version: 1`、`timezone`、`category_order` 及 `days`。每个日期有 `date`、简短 `coverage` 和 `items`；每项有 `id/category/project/progress/follow_up/evidence`，evidence 至少一条非空引用，只保存到工作目录 ledger，不写进四列表格

生成器特性：

- 日期有效、时区明确、项目有稳定 id 及来源；同一输入不允许重复日期或重复 id
- 合并保留其他日期及同日未更新事项；同一天相同 id 更新，不重复追加日期段
- 空日期输入不生成空日期段，也不清除历史。不能用空输入制造当天的空日报或复制历史冒充当日产出
- 需要纠正并移除误收录行时，可在该日期传 `remove_ids`；仅用户明确纠正或核实误收录后使用，移除不存在的 id 会报错
- 输出文件必须是新路径。默认文件名已存在时使用如 `工作日报-YYYYMMDD-修订02.xlsx`，不直接覆盖原件
- 同日确认要传该行完整最新描述，保留已核实的其他进展；生成器按 id 替换整项，不理解句子中的证据增量

## 保留最新模板和手工改动

生成器适用于随包标准模板。若用户改变列宽、字体、分类版式或增加内容，应读当前实际 Excel，按其最新模板副本修改；不能通过默认生成器重建来抹掉这些改动。读取合并分类时先向下展开分类值，才能完整恢复所有项目

## 验收

1. 对照本次来源与用户确认检查措辞：打开不等于修改，提交不等于批准，计划不等于完成
2. 比较历史日期/项目及内容，确保只改变用户已纠正或本次更新的项；日期不重复，同一天分类合并不漏项目
3. 回读导出的 xlsx：单工作表、四列表头、真实日期、A4 冻结、全部非空内容居中、无公式错误
4. 查看渲染图，尤其长文本、同类多项目和第二个日期的配色，所有内容可读且没有裁切
5. 用户要求或有可用原生 Excel 环境时按相应工具流程回读；未做原生 Excel 回读就不宣称通过

内部 ledger、来源引用、核查日志和预览留在 work，向用户交付简报与最终 Excel。定时运行只在有当天有效内容时生成新文件
